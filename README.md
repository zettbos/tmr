# TMR - Tamara Delivery PRO

Aplikasi Web & PWA Manajemen Logistik, Pengantaran & Operasional Toko Bangunan Tamara (TMR).

## 🚀 Fitur Utama
- **Pelacakan Resi Publik:** Pelacakan pesanan secara real-time via kode resi `TMR-MMDD-XXXX`.
- **Manajemen Pesanan:** Alur pesanan dari Masuk, Dimuat, Pengantaran, hingga Selesai.
- **Pengecekan Checker:** Verifikasi muatan barang fisik sebelum armada berangkat.
- **Modul Armada & Sopir:** Pencatatan KM, BBM, riwayat oli, servis, dan legalitas pajak kendaraan.
- **SOP Digital:** Prosedur operasional standar terintegrasi dengan checklist dan bukti foto.
- **Database Terpusat:** Didukung oleh Supabase Cloud (PostgreSQL 15+) berkecepatan tinggi.

## 🛠️ Tech Stack
- **Frontend:** Single Page Application (HTML5, Tailwind CSS, FontAwesome, Leaflet.js)
- **Backend/Database:** Supabase (PostgreSQL, Row Level Security, Storage Buckets)
- **Adapter Engine:** Universal GAS-to-Supabase Adapter (`supabase-gas-adapter.js`)
- **Deployment:** Vercel Cloud Serverless Platform

## 📱 PWA / APK Support
Aplikasi ini mendukung instalasi PWA di Android dan iOS (Add to Home Screen) dengan label icon **TMR**.
